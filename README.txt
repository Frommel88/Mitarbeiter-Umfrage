MVG Workshop-Demo fuer GitHub Pages

1. Neues oeffentliches GitHub-Repository erstellen (z.B. mvg-workshop-demo).
2. index.html aus diesem ZIP im Stammverzeichnis hochladen.
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. Nach Bereitstellung lautet die Adresse normalerweise https://BENUTZERNAME.github.io/mvg-workshop-demo/
5. Diese URL als QR-Code teilen.

WICHTIG: Nur erfundene Angaben verwenden. Die Seite ist oeffentlich erreichbar. Export und E-Mail sind deaktiviert. GitHub kann technische Zugriffsdaten verarbeiten.
